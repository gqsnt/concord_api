# Provenance

Research date: 2026-11-07. No real NeoWs request was sent. The NASA site is JavaScript-rendered; the public search index and NASA's own published source supplied its dynamically rendered text.

- [NASA Open APIs](https://api.nasa.gov/) — key usage, constrained DEMO_KEY, and NeoWs endpoint examples (2026-11-07).
- [NASA api-docs repository](https://github.com/nasa/api-docs) — identifies the site's dynamic `apis.json` source (2026-11-07).
- [NASA API listings, apis.json](https://github.com/nasa/api-docs/blob/gh-pages/assets/json/apis.json) — feed dates, lookup example, browse example (2026-11-07).
- [Independent NeoWs collection](https://github.com/api-evangelist/nasa-gov/blob/main/collections/asteroids-neows.opencollection.json) — browse `page` and `size` query parameters (2026-11-07); this is not NASA documentation and does not establish their bounds.

The documentation examples specify requests, not response examples. All fixture bodies below are **authored synthetic**; values and error document do not assert actual provider data or exact error schema. The two documented date and lookup inputs inform the test requests, not the expected returned asteroid.

| Fixture | Derivation and role |
| --- | --- |
| `feed.json` | Synthetic date-grouped feed, one object and a secret-bearing synthetic link; dates and lookup ID echo NASA's request examples. |
| `browse.json` | Synthetic paginated browse page, object and secret-bearing link. |
| `lookup-feed.json` | Synthetic lookup of the feed object. |
| `lookup-browse.json` | Synthetic lookup of the browse object. |
| `key-error.json` | Synthetic 403 key/quota-style response echoing a fake key; no claim about NASA's error schema or exact status. |
| `malformed.json` | Synthetic invalid JSON. Truncation, media mismatch, and an oversized body are generated by the test server. |

Dependencies already present in the baseline lockfile: Concord 4.2.0, serde 1.0.229, tokio 1.54.1, and the workspace testserver 0.0.0. No new third-party crate or changed dependency version was introduced.
