sources above. Titles, abstracts, DOI, totals and cursor tokens assert no biomedical facts.

their fixture metadata and relationships are invented. JSON is an authored counterpart

`fixtures/README.md` supplies an independent wire/transition specification, written from
these sources and the authored scenario. Tests assert that specification; no golden
expectations were generated by calling SDK encoders/decoders. The inline response literals,
non-UTF-8 bytes, duplicate/missing/wrong media headers, oversized whitespace chunks,
broken chunks, timeouts, redirects, status matrix and Retry-After fields in `protocol.rs`
are also authored synthetic faults. Oversized bodies are generated locally rather than
checking in hundreds of kilobytes. Only the explicit no-network DTD fault contains an
external resource URL; the parser refuses it and never resolves it.
