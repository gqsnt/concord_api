# An object store like Amazon S3

*[Concord](../../README.md) · [docs](../README.md) · examples · previous: [Riot Games](riot.md) · next: [Stripe](stripe.md)*

For a Rust developer who talks to Amazon S3, or to a store that speaks its API: a client of 17 operations to copy from. It is the example of a signature on every request, of XML, of objects read as a stream of bytes, and of an upload in several parts.

S3, as Concord sees it. A bucket is an address, in the host (`https://photos.s3.eu-west-1.amazonaws.com`) or in the path (`https://s3.eu-west-1.amazonaws.com/photos`): the handle of a bucket takes that address whole, as a `Base`, so one tree serves both, and bucket names with dots too. The list of buckets lives on the global host. Who you are: an AWS signature (version 4) on every request, made from the request as it leaves, so it is a middleware, not a header of the description. A list comes in pages by a token or by markers, with `IsTruncated`: the pagers are the author's. S3 answers in XML, and says no with an XML `Error` document, read into `S3Problem`; a copy and the end of an upload can fail inside a `200`. An object is bytes: `read Stream;` gives them as they come. AWS's own reference: [the S3 API](https://docs.aws.amazon.com/AmazonS3/latest/API/Welcome.html). `(unsure)` marks a detail of a provider that is not checked.

## The description

```rust
use concord::http::HeaderMap;
use concord::read::Stream;
use concord::{by_cursor, Base, Body, ByteStream};

concord::api! {
    /// An object store that speaks S3: buckets, objects, and uploads in several parts.
    pub client ObjectStore(region: String, credentials: Credentials) {
        read Xml;
        problem S3Problem;
        /// Signs every request: each page, each try.
        middleware Signed::new(credentials.clone(), region.clone());

        part version(version_id?: String) {
            query { "versionId" = version_id; }
        }
        part conditions(
            if_match?: String,
            if_modified_since?: String,
            if_unmodified_since?: String,
        ) {
            headers {
                "if-match" = if_match;
                "if-modified-since" = if_modified_since;
                "if-unmodified-since" = if_unmodified_since;
            }
        }
        part write_headers(
            content_type?: String,
            cache_control?: String,
            storage_class?: String,
        ) {
            headers {
                "content-type" = content_type;
                "cache-control" = cache_control;
                "x-amz-storage-class" = storage_class;
            }
        }
        part listing(prefix?: String, delimiter?: String) {
            query { prefix; delimiter; }
        }

        GET list_buckets(
            max_buckets?: u32, continuation_token?: String, prefix?: String,
        ) -> BucketsPage {
            base "https://s3.amazonaws.com";
            query {
                "max-buckets" = max_buckets;
                "continuation-token" = continuation_token;
                prefix;
            }
            paginate by_cursor(continuation_token, BucketsPage::next);
        }

        scope bucket(url: Base) {
            base url;

            /// An error keeps its status and the `x-amz-bucket-region` header.
            HEAD head();
            /// In `us-east-1`, no configuration; anywhere else, its `LocationConstraint`.
            PUT create(configuration?: CreateBucketConfiguration) {
                body create_bucket_body(configuration);
                idempotent false;
            }
            DELETE delete();

            GET list_objects(
                max_keys?: u32, continuation_token?: String,
                start_after?: String, fetch_owner?: bool, ..listing,
            ) -> ObjectsPage {
                query {
                    "list-type" = "2";
                    "encoding-type" = "url";
                    "max-keys" = max_keys;
                    "continuation-token" = continuation_token;
                    "start-after" = start_after;
                    "fetch-owner" = fetch_owner;
                }
                paginate checked_cursor(continuation_token, ObjectsPage::next);
            }
            /// A key that could not be deleted is in `DeleteResult.errors`, under a `200`.
            POST delete_objects(batch: DeleteBatch) -> DeleteResult {
                query { "delete" = ""; }
                body xml(batch);
            }
            GET list_multipart_uploads(
                max_uploads?: u32, key_marker?: String,
                upload_id_marker?: String, ..listing,
            ) -> UploadsPage {
                query {
                    "uploads" = "";
                    "encoding-type" = "url";
                    "max-uploads" = max_uploads;
                    "key-marker" = key_marker;
                    "upload-id-marker" = upload_id_marker;
                }
                paginate uploads_after(key_marker, upload_id_marker);
            }

            scope object(key: String) {
                path "{*key}";

                GET get(range?: String, ..version, ..conditions) -> ByteStream {
                    headers { "range" = range; }
                    read Stream;
                }
                HEAD head(..version, ..conditions) -> HeaderMap {
                    status { 2xx { headers } => headers.as_map().clone() }
                }
                /// The value is the ETag; `send_full()` keeps the other headers too.
                PUT put(file: Body, size: u64, ..write_headers) -> String {
                    headers { "content-length" = size; }
                    body file;
                    status { 2xx { headers } => headers.require("etag")?.to_owned() }
                    idempotent false;
                }
                PUT copy_from(
                    source_bucket: String, source_key: String,
                    source_version?: String, source_if_match?: String,
                    metadata_directive?: String, ..write_headers,
                ) -> CopyResult {
                    headers {
                        "x-amz-copy-source" = copy_source(source_bucket, source_key, source_version);
                        "x-amz-copy-source-if-match" = source_if_match;
                        "x-amz-metadata-directive" = metadata_directive;
                    }
                    status { 2xx { body } => copy_ok(body)? }
                    idempotent false;
                }
                DELETE delete(..version) {
                    idempotent version_id.as_ref().is_some_and(|id| id != "null");
                }
                POST create_multipart_upload(..write_headers) -> InitiatedUpload {
                    query { "uploads" = ""; }
                }

                scope upload(upload_id: String) {
                    query { "uploadId" = upload_id; }

                    PUT upload_part(part_number: u32, file: Body, size: u64) -> String {
                        query { "partNumber" = part_number; }
                        headers { "content-length" = size; }
                        body file;
                        status { 2xx { headers } => headers.require("etag")?.to_owned() }
                    }
                    POST complete(parts: CompleteUpload) -> CompleteResult {
                        body xml(parts);
                        status { 2xx { body } => complete_ok(body)? }
                    }
                    DELETE abort();
                    GET list_parts(
                        max_parts?: u32, part_number_marker?: u32,
                    ) -> PartsPage {
                        query {
                            "max-parts" = max_parts;
                            "part-number-marker" = part_number_marker;
                        }
                        paginate checked_cursor(part_number_marker, PartsPage::next);
                    }
                }
            }
        }
    }
}
```

The seventeen operations: ListBuckets; HeadBucket, CreateBucket, DeleteBucket; ListObjectsV2, DeleteObjects, ListMultipartUploads; GetObject, HeadObject, PutObject, CopyObject, DeleteObject; CreateMultipartUpload, UploadPart, CompleteMultipartUpload, AbortMultipartUpload, ListParts.

## Beside the description

The data types are plain `serde` types for XML, named here and not printed: `S3Problem` (`Code`, `Message`, `RequestId`), `BucketsPage`, `ObjectsPage` (`objects`, `common_prefixes`, `is_truncated`, `next_continuation_token`), `UploadsPage`, `PartsPage`, `CreateBucketConfiguration`, `DeleteBatch`, `DeleteResult`, `InitiatedUpload`, `CompleteUpload` (with `from_etags`), `CopyResult`, `CompleteResult`. The listings ask for `encoding-type=url`, so the keys in them are decoded once, by the types.

What the description names: the credentials, the arms that find an error inside a `200`, the header of a copy, the pagers, and the metadata of the caller.

```rust
use concord::http::{HeaderName, HeaderValue};
use concord::page::{Call, Slot};
use concord::{reqwest, Answer, Fail, Secret};
use serde::Deserialize;

type BoxError = Box<dyn std::error::Error + Send + Sync>;

/// The keys that sign: given by the caller, never fetched or renewed here.
#[derive(Clone, Debug)]
pub struct Credentials {
    pub access_key_id: String,
    pub secret_access_key: Secret,
    pub session_token: Option<Secret>,
}

/// A copy, or the completion of an upload, can fail inside a `200`: the root of the XML says which.
#[derive(Debug, Deserialize)]
pub enum CopyReply {
    #[serde(rename = "CopyObjectResult")]
    Success(CopyResult),
    #[serde(rename = "Error")]
    Error(S3Problem),
}

#[derive(Debug, Deserialize)]
pub enum CompleteReply {
    #[serde(rename = "CompleteMultipartUploadResult")]
    Success(CompleteResult),
    #[serde(rename = "Error")]
    Error(S3Problem),
}

pub fn copy_ok(reply: CopyReply) -> Result<CopyResult, S3Problem> {
    match reply {
        CopyReply::Success(value) => Ok(value),
        CopyReply::Error(problem) => Err(problem),
    }
}

pub fn complete_ok(reply: CompleteReply) -> Result<CompleteResult, S3Problem> {
    match reply {
        CompleteReply::Success(value) => Ok(value),
        CompleteReply::Error(problem) => Err(problem),
    }
}

/// `x-amz-copy-source`: a header is not percent-encoded by Concord, so this does it.
pub fn copy_source(bucket: &str, key: &str, version: &Option<String>) -> String {
    let mut source = format!("/{}/{}", encoded(bucket, false), encoded(key, true));
    if let Some(id) = version {
        source.push_str("?versionId=");
        source.push_str(&encoded(id, false));
    }
    source
}

fn encoded(text: &str, keep_slashes: bool) -> String {
    let mut out = String::new();
    for byte in text.bytes() {
        if byte.is_ascii_alphanumeric() || b"-._~".contains(&byte) || (keep_slashes && byte == b'/') {
            out.push(char::from(byte));
        } else {
            out.push_str(&format!("%{byte:02X}"));
        }
    }
    out
}

impl BucketsPage {
    pub fn next(&self) -> Option<String> {
        self.continuation_token.clone()
    }
}

/// The next marker of a page: none at the end, or a Mismatch when a truncated page has none.
pub type NextMarker<T> = Result<Option<T>, Fail<S3Problem>>;

fn truncated_next<T: Clone>(more: bool, next: &Option<T>) -> NextMarker<T> {
    if !more {
        return Ok(None);
    }
    next.clone().map(Some).ok_or_else(|| concord::mismatch("a truncated page with no next marker"))
}

impl ObjectsPage {
    pub fn next(&self) -> NextMarker<String> {
        truncated_next(self.is_truncated, &self.next_continuation_token)
    }
}

impl PartsPage {
    pub fn next(&self) -> NextMarker<u32> {
        truncated_next(self.is_truncated, &self.next_part_number_marker)
    }
}

/// `by_cursor`, with a next value that may fail.
pub fn checked_cursor<C, S, V>(slot: S, next: fn(&C::Value) -> NextMarker<V>)
    -> impl Fn(C, &Answer<C::Value>) -> Result<Option<C>, Fail<S3Problem>> + Send + 'static
where
    C: Call<Problem = S3Problem>,
    S: Slot<C, Value = V>,
    V: Send + 'static,
{
    move |call, answer| Ok(next(answer.value())?.map(|value| slot.set(call, value)))
}

/// The uploads in progress move by two markers together.
pub fn uploads_after<C, K, U>(key: K, upload: U)
    -> impl Fn(C, &Answer<UploadsPage>) -> Result<Option<C>, Fail<S3Problem>> + Send + 'static
where
    C: Call<Value = UploadsPage, Problem = S3Problem>,
    K: Slot<C, Value = String>,
    U: Slot<C, Value = String>,
{
    move |call, answer| {
        let page = answer.value();
        if !page.is_truncated {
            return Ok(None);
        }
        let missing = || concord::mismatch("a truncated page with no next marker");
        let next_key = page.next_key_marker.clone().ok_or_else(missing)?;
        let next_upload = page.next_upload_id_marker.clone().ok_or_else(missing)?;
        Ok(Some(upload.set(key.set(call, next_key), next_upload)))
    }
}

/// Metadata of the caller's (`x-amz-meta-*`), for `.edit_request(…)`: the description names
/// every key, and these keys are the caller's. Checked before the call is built.
pub fn metadata<K: AsRef<str>, V: AsRef<str>>(
    entries: impl IntoIterator<Item = (K, V)>,
) -> Result<impl Fn(&mut reqwest::Request) + Send + Sync + 'static, BoxError> {
    let mut headers = Vec::new();
    for (suffix, value) in entries {
        let name = format!("x-amz-meta-{}", suffix.as_ref());
        headers.push((HeaderName::try_from(name)?, HeaderValue::try_from(value.as_ref())?));
    }
    Ok(move |request: &mut reqwest::Request| {
        for (name, value) in &headers {
            request.headers_mut().insert(name.clone(), value.clone());
        }
    })
}
```

The XML reader and writer, and the signer. This block needs three crates: `quick-xml` (feature `serialize`), `aws-sigv4` and `aws-credential-types`, and for the checksum `md-5` and `base64`. The signer computes; it sends nothing.

```rust
use aws_sigv4::http_request::{
    sign, PayloadChecksumKind, PercentEncodingMode, SignableBody, SignableRequest, SigningSettings,
    UriPathNormalizationMode,
};
use aws_sigv4::sign::v4;
use base64::{engine::general_purpose::STANDARD, Engine};
use concord::http::{HeaderName, HeaderValue};
use concord::read::{Incoming, ReadError, Reader};
use concord::transport::{TransportError, TryInfo};
use concord::{reqwest, Body, Middleware, Next};
use md5::{Digest, Md5};
use serde::{de::DeserializeOwned, Serialize};
use std::time::SystemTime;

type BoxError = Box<dyn std::error::Error + Send + Sync>;

/// `read Xml;`: the body, at most 10 MiB, read by `quick-xml`.
#[derive(Clone, Copy, Debug)]
pub struct Xml;

impl<T: DeserializeOwned + Send> Reader<T> for Xml {
    async fn read(&self, body: Incoming) -> Result<T, ReadError> {
        let bytes = body.bytes(10 * concord::MIB).await?;
        quick_xml::de::from_reader(&bytes[..])
            .map_err(|error| ReadError::not_the_type(bytes).with_details(error.to_string()))
    }
}

/// `body xml(batch);`
pub fn xml<T: Serialize>(value: &T) -> Result<Body, quick_xml::SeError> {
    Ok(Body::new(quick_xml::se::to_string(value)?, "application/xml"))
}

pub fn create_bucket_body(value: &Option<CreateBucketConfiguration>) -> Result<Body, quick_xml::SeError> {
    match value {
        Some(configuration) => xml(configuration),
        None => Ok(Body::new("", "application/xml")),
    }
}

/// `middleware Signed::new(credentials.clone(), region.clone());`: AWS Signature Version 4, on
/// every try. The list of buckets is signed for `us-east-1`; everything else for the region.
/// A delete of many keys also needs a `content-md5` of its body: the description cannot make a
/// header from the bytes of a body, so the signer adds it, before it signs.
pub struct Signed {
    credentials: Credentials,
    region: String,
}

impl Signed {
    pub fn new(credentials: Credentials, region: String) -> Self {
        Signed { credentials, region }
    }

    fn sign(&self, request: &mut reqwest::Request, endpoint: &str) -> Result<(), BoxError> {
        if endpoint == "object_store.bucket.delete_objects" {
            let bytes = request.body().and_then(|body| body.as_bytes()).ok_or("no body in memory")?;
            let digest = STANDARD.encode(Md5::digest(bytes));
            request.headers_mut().insert("content-md5", HeaderValue::from_str(&digest)?);
        }
        let identity = aws_credential_types::Credentials::new(
            &self.credentials.access_key_id,
            self.credentials.secret_access_key.expose().to_string(),
            self.credentials.session_token.as_ref().map(|token| token.expose().to_string()),
            None,
            "concord",
        )
        .into();
        let region = if endpoint == "object_store.list_buckets" { "us-east-1" } else { &self.region };
        let mut settings = SigningSettings::default();
        settings.percent_encoding_mode = PercentEncodingMode::Single;
        settings.uri_path_normalization_mode = UriPathNormalizationMode::Disabled;
        settings.payload_checksum_kind = PayloadChecksumKind::XAmzSha256;
        let params = v4::SigningParams::builder()
            .identity(&identity)
            .region(region)
            .name("s3")
            .time(SystemTime::now())
            .settings(settings)
            .build()?
            .into();
        let payload = match request.body() {
            None => SignableBody::Bytes(&[]),
            Some(body) => match body.as_bytes() {
                Some(bytes) => SignableBody::Bytes(bytes),
                None => SignableBody::UnsignedPayload,     // a stream: sent once, over HTTPS
            },
        };
        let headers = request.headers().iter()
            .map(|(name, value)| Ok((name.as_str(), value.to_str()?)))
            .collect::<Result<Vec<_>, concord::http::header::ToStrError>>()?;
        let signable = SignableRequest::new(
            request.method().as_str(), request.url().as_str(), headers.into_iter(), payload,
        )?;
        let (instructions, _) = sign(signable, &params)?.into_parts();
        for (name, value) in instructions.headers() {
            let mut value = HeaderValue::from_str(value)?;
            value.set_sensitive(name == "authorization" || name == "x-amz-security-token");
            request.headers_mut().insert(HeaderName::from_bytes(name.as_bytes())?, value);
        }
        Ok(())
    }
}

impl Middleware for Signed {
    async fn handle(&self, mut request: reqwest::Request, info: TryInfo, next: Next<'_>)
        -> Result<reqwest::Response, TransportError>
    {
        self.sign(&mut request, info.endpoint())
            .map_err(|error| TransportError::blocked().with_source(error))?;
        next.send(request, info).await
    }
}
```

A stream body cannot be read twice, so it is signed as `UNSIGNED-PAYLOAD` (the request itself is still signed); send it over HTTPS, with its length. A store that refuses that mode wants the bytes in memory: an upload in parts. Each try is signed again, with a new time. Whether every S3-compatible store accepts the mode is (unsure).

## Calling it

```rust
use concord::{Base, Body, ByteStream};

type BoxError = Box<dyn std::error::Error + Send + Sync>;

/// A client for one region, and a bucket by its address: the bucket in the host, or in the path.
pub fn connect(credentials: Credentials) -> Result<(ObjectStore, object_store::Bucket), BoxError> {
    let store = ObjectStore::new("eu-west-1", credentials);
    let photos: Base = "https://photos.s3.eu-west-1.amazonaws.com".parse()?;
    // Or, with the bucket in the path: "https://s3.eu-west-1.amazonaws.com/photos".
    let bucket = store.bucket(photos);
    Ok((store, bucket))
}

/// Every object under a prefix, all pages, with the "folders" that the delimiter makes.
pub async fn list(bucket: &object_store::Bucket) -> object_store::Result<()> {
    let mut pages = bucket.list_objects().prefix("reports/").delimiter("/").max_keys(500).pages();
    while let Some(page) = pages.try_next().await? {
        for object in page.objects {
            println!("{}: {} bytes", object.key, object.size);
        }
        for folder in page.common_prefixes {
            println!("folder: {}", folder.prefix);
        }
    }
    Ok(())
}

/// Write an object with metadata of yours, read its headers, copy it to another key.
pub async fn put_and_copy(bucket: &object_store::Bucket) -> Result<(), BoxError> {
    let object = bucket.object("reports/2026/november.txt");
    let etag = object.put(Body::new("hello", "text/plain"), 5)
        .edit_request(metadata([("owner", "finance")])?)
        .await?;
    let head = object.head().await?;
    println!("{:?}", head.get("x-amz-meta-owner"));
    bucket.object("reports/latest.txt")
        .copy_from("photos", "reports/2026/november.txt")
        .source_if_match(etag)
        .await?;
    Ok(())
}

/// The object again, only if it changed since its ETag. `None`: it did not (a `304`).
pub async fn if_changed(bucket: &object_store::Bucket, etag: &str) -> object_store::Result<Option<ByteStream>> {
    let answer = bucket.object("large.bin").get().send_if_none_match(etag).await?;
    Ok(answer.into_value())
}

/// The first kilobyte of an object, as a stream of pieces.
pub async fn first_kilobyte(bucket: &object_store::Bucket) -> object_store::Result<Vec<u8>> {
    let answer = bucket.object("large.bin").get().range("bytes=0-1023").send_full().await?;
    println!("{}", answer.status());                       // 206: a part of the object
    let mut stream = answer.into_value();
    let mut bytes = Vec::new();
    while let Some(piece) = stream.try_next().await? {
        bytes.extend_from_slice(&piece);
    }
    Ok(bytes)
}

/// An upload in parts (one part here; the last part may be small), aborted when a part fails.
pub async fn upload(bucket: &object_store::Bucket, data: Vec<u8>) -> object_store::Result<String> {
    let object = bucket.object("backup.bin");
    let started = object.create_multipart_upload().content_type("application/octet-stream").await?;
    let upload = object.upload(started.upload_id);
    let size = data.len() as u64;
    let etag = match upload.upload_part(1, Body::new(data, "application/octet-stream"), size).await {
        Ok(etag) => etag,
        Err(error) => {
            upload.abort().await?;
            return Err(error);
        }
    };
    let done = upload.complete(CompleteUpload::from_etags([(1, etag)])).await?;
    Ok(done.etag)
}
```

## What fits badly, and the way out

| S3 wants | What to write |
|---|---|
| A key with a whole piece `.` or `..` (`a/../b`): a valid key. | It cannot be sent: the URL type of `reqwest` removes the piece, and the request is refused when it is built. For such keys: an HTTP library that keeps the path as it is given, or the AWS SDK. |
| Metadata whose names the caller chooses: `x-amz-meta-*`. The description names every key. | `metadata([…])` above, given to `.edit_request(…)`: the headers go on before the signer runs. |
| `content-md5` of the body of a `DeleteObjects`: a header made from the bytes of the body. | The signer adds it, for that endpoint by its name, before it signs. |
| An error inside a `200`, for a copy and for the end of an upload. | An arm on the 2xx that reads the root of the XML (`CopyReply`), and gives `Err(S3Problem)`: the client's own refusal. |
| Two markers that move together (the uploads in progress). | A pager of yours with two slots, `uploads_after`. |
| A truncated page with no next marker, which should not end the list quietly. | A pager that returns a `Result`: a Mismatch, after the page that came was given. |
| A signature for the region of the bucket, and `us-east-1` for the list of buckets. | A middleware sees the request, not the description: it chooses by `info.endpoint()`. |
| A large upload that survives a lost connection. A stream body is sent once. | An upload in parts, each in memory, and a loop of yours that sends a part again. |
| A text in a header, encoded: `x-amz-copy-source`. Concord does not percent-encode a header. | `copy_source` encodes it. |
