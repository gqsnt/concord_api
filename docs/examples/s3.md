# An object store like Amazon S3

*[Concord](../../README.md) · [docs](../README.md) · examples · previous: [Riot Games](riot.md) · next: [Stripe](stripe.md)*

This page is for a Rust developer who talks to Amazon S3, or to a store that implements its API. It gives a client with 17 operations that you can copy, and shows a signature on every request, XML, objects read as a stream of bytes, and an upload in several parts.

Here is S3 as Concord sees it. A bucket is an address, either in the host (`https://photos.s3.eu-west-1.amazonaws.com`) or in the path (`https://s3.eu-west-1.amazonaws.com/photos`). The handle of a bucket takes that whole address as a `Base`, so one tree serves both forms, and bucket names with dots as well. The list of buckets lives on the global host. Authentication is an AWS signature (version 4) on every request, computed from the request as it is sent, so it is a middleware layer rather than a header in the description. Lists are paginated, by a token or by markers, with `IsTruncated`: `by_cursor` with `has_more` for a token, and a pager of the author's own for the two markers of the uploads. S3 responds in XML, and rejects a request with an XML `Error` document, read into `S3Problem`; a copy and the completion of an upload can fail inside a `200`. An object is bytes, and `read Stream;` yields them as they arrive. AWS's own reference is [the S3 API](https://docs.aws.amazon.com/AmazonS3/latest/API/Welcome.html). `(unsure)` marks a detail about the provider that has not been checked.

## The description

```rust
use concord::http::HeaderMap;
use concord::read::Stream;
use concord::{by_cursor, Base, Body, ByteStream};

concord::api! {
    /// An object store that speaks S3: buckets, objects, and uploads in several parts.
    pub client ObjectStore(region: String, credentials: Credentials, origins: Vec<Base>) {
        read Xml;
        problem S3Problem;
        /// Signs every request: each page, each attempt.
        middleware Signed::new(credentials.clone(), region.clone(), origins.clone());

        part version(version_id?: String) {
            query { "versionId" = version_id; }
        }
        part conditions(
            if_match?: String,
            if_modified_since?: String,
            if_unmodified_since?: String,
        ) {
            headers {
                "if-match" = if_match;
                "if-modified-since" = if_modified_since;
                "if-unmodified-since" = if_unmodified_since;
            }
        }
        part write_headers(
            content_type?: String,
            cache_control?: String,
            storage_class?: String,
        ) {
            headers {
                "content-type" = content_type;
                "cache-control" = cache_control;
                "x-amz-storage-class" = storage_class;
            }
        }
        part listing(prefix?: String, delimiter?: String) {
            query { prefix; delimiter; }
        }

        GET list_buckets(
            max_buckets?: u32, continuation_token?: String, prefix?: String,
        ) -> BucketsPage {
            base "https://s3.amazonaws.com";
            query {
                "max-buckets" = max_buckets;
                "continuation-token" = continuation_token;
                prefix;
            }
            paginate by_cursor(continuation_token, BucketsPage::next);
        }

        scope bucket(url: Base) {
            base url;

            /// An error keeps its status and the `x-amz-bucket-region` header.
            HEAD head();
            /// In `us-east-1`, no configuration; anywhere else, its `LocationConstraint`.
            PUT create(configuration?: CreateBucketConfiguration) {
                body create_bucket_body(configuration);
                idempotent false;
            }
            DELETE delete();

            GET list_objects(
                max_keys?: u32, continuation_token?: String,
                start_after?: String, fetch_owner?: bool, ..listing,
            ) -> ObjectsPage {
                query {
                    "list-type" = "2";
                    "encoding-type" = "url";
                    "max-keys" = max_keys;
                    "continuation-token" = continuation_token;
                    "start-after" = start_after;
                    "fetch-owner" = fetch_owner;
                }
                paginate by_cursor(continuation_token, |page| page.next_continuation_token.clone())
                    .has_more(|page| page.is_truncated);
            }
            /// A key that could not be deleted is in `DeleteResult.errors`, under a `200`.
            POST delete_objects(batch: DeleteBatch) -> DeleteResult {
                query { "delete" = ""; }
                body xml(batch);
            }
            GET list_multipart_uploads(
                max_uploads?: u32, key_marker?: String,
                upload_id_marker?: String, ..listing,
            ) -> UploadsPage {
                query {
                    "uploads" = "";
                    "encoding-type" = "url";
                    "max-uploads" = max_uploads;
                    "key-marker" = key_marker;
                    "upload-id-marker" = upload_id_marker;
                }
                paginate uploads_after(key_marker, upload_id_marker);
            }

            scope object(key: String) {
                path "{*key}";

                GET get(range?: String, ..version, ..conditions) -> ByteStream {
                    headers { "range" = range; }
                    read Stream;
                }
                HEAD head(..version, ..conditions) -> HeaderMap {
                    status { 2xx { headers } => headers.as_map().clone() }
                }
                /// The value is the ETag; `send_full()` keeps the other headers too.
                PUT put(file: Body, size: u64, ..write_headers) -> String {
                    headers { "content-length" = size; }
                    body file;
                    status { 2xx { headers } => headers.require("etag")?.to_owned() }
                    idempotent false;
                }
                PUT copy_from(
                    source_bucket: String, source_key: String,
                    source_version?: String, source_if_match?: String,
                    metadata_directive?: String, ..write_headers,
                ) -> CopyResult {
                    headers {
                        "x-amz-copy-source" = copy_source(source_bucket, source_key, source_version);
                        "x-amz-copy-source-if-match" = source_if_match;
                        "x-amz-metadata-directive" = metadata_directive;
                    }
                    status { 2xx { body } => copy_ok(body)? }
                    idempotent false;
                }
                DELETE delete(..version) {
                    idempotent version_id.as_ref().is_some_and(|id| id != "null");
                }
                POST create_multipart_upload(..write_headers) -> InitiatedUpload {
                    query { "uploads" = ""; }
                }

                scope upload(upload_id: String) {
                    query { "uploadId" = upload_id; }

                    PUT upload_part(part_number: u32, file: Body, size: u64) -> String {
                        query { "partNumber" = part_number; }
                        headers { "content-length" = size; }
                        body file;
                        status { 2xx { headers } => headers.require("etag")?.to_owned() }
                    }
                    POST complete(parts: CompleteUpload) -> CompleteResult {
                        body xml(parts);
                        status { 2xx { body } => complete_ok(body)? }
                    }
                    DELETE abort();
                    GET list_parts(
                        max_parts?: u32, part_number_marker?: u32,
                    ) -> PartsPage {
                        query {
                            "max-parts" = max_parts;
                            "part-number-marker" = part_number_marker;
                        }
                        paginate by_cursor(part_number_marker, |page| page.next_part_number_marker)
                            .has_more(|page| page.is_truncated);
                    }
                }
            }
        }
    }
}
```

The seventeen operations: ListBuckets; HeadBucket, CreateBucket, DeleteBucket; ListObjectsV2, DeleteObjects, ListMultipartUploads; GetObject, HeadObject, PutObject, CopyObject, DeleteObject; CreateMultipartUpload, UploadPart, CompleteMultipartUpload, AbortMultipartUpload, ListParts.

## Beside the description

The data types are plain `serde` types for XML, named here but not shown: `S3Problem` (`Code`, `Message`, `RequestId`), `BucketsPage`, `ObjectsPage` (`objects`, `common_prefixes`, `is_truncated`, `next_continuation_token`, read from `Contents`, `CommonPrefixes`, `IsTruncated` and `NextContinuationToken`), `UploadsPage`, `PartsPage` (`parts`, each with `PartNumber`, `ETag` and `Size`; `is_truncated`; `next_part_number_marker`), `CreateBucketConfiguration`, `DeleteBatch`, `DeleteResult`, `InitiatedUpload`, `CompleteUpload` (with `from_etags`), `CopyResult`, `CompleteResult`. The listings request `encoding-type=url`, so the keys in them are decoded once, by the types.

The description names these Rust items: the credentials, the arms that detect an error inside a `200`, the header of a copy, the pager of the uploads, and the caller's metadata.

```rust
use concord::http::{HeaderName, HeaderValue};
use concord::page::Slot;
use concord::{reqwest, Answer, Fail};
use serde::Deserialize;

type BoxError = Box<dyn std::error::Error + Send + Sync>;

pub use concord::sign::Credentials;

/// A copy, or the completion of an upload, can fail inside a `200`: the root of the XML says which.
#[derive(Debug, Deserialize)]
pub enum CopyReply {
    #[serde(rename = "CopyObjectResult")]
    Success(CopyResult),
    #[serde(rename = "Error")]
    Error(S3Problem),
}

#[derive(Debug, Deserialize)]
pub enum CompleteReply {
    #[serde(rename = "CompleteMultipartUploadResult")]
    Success(CompleteResult),
    #[serde(rename = "Error")]
    Error(S3Problem),
}

pub fn copy_ok(reply: CopyReply) -> Result<CopyResult, S3Problem> {
    match reply {
        CopyReply::Success(value) => Ok(value),
        CopyReply::Error(problem) => Err(problem),
    }
}

pub fn complete_ok(reply: CompleteReply) -> Result<CompleteResult, S3Problem> {
    match reply {
        CompleteReply::Success(value) => Ok(value),
        CompleteReply::Error(problem) => Err(problem),
    }
}

/// `x-amz-copy-source`: a header is not percent-encoded by Concord, so this does it.
pub fn copy_source(bucket: &str, key: &str, version: &Option<String>) -> String {
    let mut source = format!("/{}/{}", encoded(bucket, false), encoded(key, true));
    if let Some(id) = version {
        source.push_str("?versionId=");
        source.push_str(&encoded(id, false));
    }
    source
}

fn encoded(text: &str, keep_slashes: bool) -> String {
    let mut out = String::new();
    for byte in text.bytes() {
        if byte.is_ascii_alphanumeric() || b"-._~".contains(&byte) || (keep_slashes && byte == b'/') {
            out.push(char::from(byte));
        } else {
            out.push_str(&format!("%{byte:02X}"));
        }
    }
    out
}

impl BucketsPage {
    pub fn next(&self) -> Option<String> {
        self.continuation_token.clone()
    }
}

/// The uploads in progress move by two markers together: a truncated page that lacks either
/// one is a Mismatch.
pub fn uploads_after<C, K, U>(key: K, upload: U)
    -> impl Fn(C, &Answer<UploadsPage>) -> Result<Option<C>, Fail<S3Problem>> + Send + 'static
where
    C: concord::page::Call<Value = UploadsPage, Problem = S3Problem>,
    K: Slot<C, Value = String>,
    U: Slot<C, Value = String>,
{
    move |call, answer| {
        let page = answer.value();
        if !page.is_truncated {
            return Ok(None);
        }
        let missing = || concord::mismatch("a truncated page with no next marker");
        let next_key = page.next_key_marker.clone().ok_or_else(missing)?;
        let next_upload = page.next_upload_id_marker.clone().ok_or_else(missing)?;
        Ok(Some(upload.set(key.set(call, next_key), next_upload)))
    }
}

/// The caller's own metadata (`x-amz-meta-*`), for `.edit_request(…)`: the description names
/// every key, and these keys are chosen by the caller. Checked before the call is built.
pub fn metadata<K: AsRef<str>, V: AsRef<str>>(
    entries: impl IntoIterator<Item = (K, V)>,
) -> Result<impl Fn(&mut reqwest::Request) + Send + Sync + 'static, BoxError> {
    let mut headers = Vec::new();
    for (suffix, value) in entries {
        let name = format!("x-amz-meta-{}", suffix.as_ref());
        headers.push((HeaderName::try_from(name)?, HeaderValue::try_from(value.as_ref())?));
    }
    Ok(move |request: &mut reqwest::Request| {
        for (name, value) in &headers {
            request.headers_mut().insert(name.clone(), value.clone());
        }
    })
}
```

The XML reader and writer use `quick-xml` (feature `serialize`). For example, a bulk delete of `reports/old.txt` writes this body; the signing adapter hashes these XML bytes for both the payload proof and Content-MD5:

```xml
<Delete xmlns="http://s3.amazonaws.com/doc/2006-03-01/"><Object><Key>reports/old.txt</Key></Object><Quiet>false</Quiet></Delete>
```


```rust
use concord::read::{Incoming, ReadError, Reader};
use concord::Body;
use serde::{de::DeserializeOwned, Serialize};

/// `read Xml;`: the body, at most 10 MiB, read by `quick-xml`.
#[derive(Clone, Copy, Debug)]
pub struct Xml;

impl<T: DeserializeOwned + Send> Reader<T> for Xml {
    async fn read(&self, body: Incoming) -> Result<T, ReadError> {
        let bytes = body.bytes(10 * concord::MIB).await?;
        quick_xml::de::from_reader(&bytes[..])
            .map_err(|error| ReadError::not_the_type(bytes).with_details(error.to_string()))
    }
}

/// `body xml(batch);`
pub fn xml<T: Serialize>(value: &T) -> Result<Body, quick_xml::SeError> {
    Ok(Body::new(quick_xml::se::to_string(value)?, "application/xml"))
}

pub fn create_bucket_body(value: &Option<CreateBucketConfiguration>) -> Result<Body, quick_xml::SeError> {
    match value {
        Some(configuration) => xml(configuration),
        None => Ok(Body::new("", "application/xml")),
    }
}
```

The signing adapter uses `concord::sign::SigV4` (feature `sign`), with `md-5` and `base64` for the bulk-delete checksum. Supply the allowed bucket origins when constructing the client; beside them, the list of buckets goes to the fixed global endpoint, `https://s3.amazonaws.com`, in `us-east-1`. A request to any other origin is refused before a key is used. The adapter chooses the region by endpoint and signs with `SigV4::sign_any_origin`: one signer serves the buckets and the global endpoint, and the adapter has checked the origin against them before it signs. It signs synchronously, so hashing a large buffered upload occupies the calling thread until it finishes. The fixed-origin `SigV4` middleware yields between payload chunks.

```rust
use base64::{engine::general_purpose::STANDARD, Engine};
use concord::http::HeaderValue;
use concord::sign::{body_bytes, check_origin, CanonicalPath, SigV4, SignError};
use concord::transport::{TransportError, TryInfo};
use concord::{Base, Middleware, Next};
use md5::{Digest, Md5};

/// Checks the configured bucket origins, adds the bulk-delete checksum, and delegates signing.
/// The list of buckets uses the global origin and `us-east-1`.
pub struct Signed {
    credentials: Credentials,
    region: String,
    origins: Vec<Base>,
    signer: std::sync::OnceLock<SigV4>,
}

impl Signed {
    pub fn new(credentials: Credentials, region: String, origins: Vec<Base>) -> Self {
        Self { credentials, region, origins, signer: std::sync::OnceLock::new() }
    }

    fn sign(&self, request: &mut concord::reqwest::Request, endpoint: &str) -> Result<(), SignError> {
        let global: Base = "https://s3.amazonaws.com".parse().map_err(SignError::failed)?;
        let (origin, region) = if endpoint == "object_store.list_buckets" {
            check_origin(request, &global)?;
            (&global, "us-east-1")
        } else {
            let origin = self.origins.iter().find(|base| check_origin(request, base).is_ok())
                .ok_or(SignError::WrongOrigin)?;
            (origin, self.region.as_str())
        };
        if endpoint == "object_store.bucket.delete_objects" {
            let digest = STANDARD.encode(Md5::digest(body_bytes(request)?));
            request.headers_mut().try_insert("content-md5", HeaderValue::from_str(&digest)?)
                .map_err(SignError::failed)?;
        }
        // The origin was selected from configuration, never from the outgoing URL: one
        // signer serves every origin, so it signs without its own check.
        self.signer.get_or_init(||
            SigV4::new(origin, self.credentials.clone(), region, "s3", CanonicalPath::Preserve)
                .allow_unsigned_payload()
        ).sign_any_origin(request, region)
    }
}

impl Middleware for Signed {
    async fn handle(&self, mut request: concord::reqwest::Request, info: TryInfo, next: Next<'_>)
        -> Result<concord::reqwest::Response, TransportError>
    {
        self.sign(&mut request, info.endpoint())
            .map_err(|error| TransportError::blocked().with_source(error))?;
        next.send(request, info).await
    }
}
```

A stream body is not hashed, so it is signed as `UNSIGNED-PAYLOAD` (the request itself is still signed); send it over HTTPS, with its length. A store that rejects that mode needs the bytes in memory, so use an upload in parts. Each attempt is signed again, with a new timestamp. A `Body::stream` is sent once; a `Body::repeatable` is opened again for each attempt, and signed again ([a body that is opened again](../guide/bodies.md#a-body-that-is-opened-again-for-each-attempt)). But `put` is `idempotent false;`, so the engine does not send it again after a failed connection, whatever its body: to send it again, your own loop builds the call again ([a body that is a stream](../guide/bodies.md#a-body-that-is-a-stream)). `upload_part` has no such mark, and a retry policy sends a part again when its body is in memory or repeatable. Whether every S3-compatible store accepts this mode is (unsure).

`CanonicalPath::Preserve` requires AWS path encoding: unreserved characters, slash separators and uppercase escapes. A path with a literal reserved character or a lowercase escape is refused rather than signed as it is. The paths that the description builds satisfy this requirement.

## Calling it

```rust
use concord::{Base, Body, ByteStream};

type BoxError = Box<dyn std::error::Error + Send + Sync>;

/// A client for one region, and a bucket by its address: the bucket in the host, or in the path.
pub fn connect(credentials: Credentials) -> Result<(ObjectStore, object_store::Bucket), BoxError> {
    let photos: Base = "https://photos.s3.eu-west-1.amazonaws.com".parse()?;
    // Or, with the bucket in the path: "https://s3.eu-west-1.amazonaws.com/photos".
    let store = ObjectStore::new("eu-west-1", credentials, vec![photos.clone()]);
    let bucket = store.bucket(photos);
    Ok((store, bucket))
}

/// Every object under a prefix, all pages, with the "folders" that the delimiter makes.
pub async fn list(bucket: &object_store::Bucket) -> object_store::Result<()> {
    let mut pages = bucket.list_objects().prefix("reports/").delimiter("/").max_keys(500).pages();
    while let Some(page) = pages.try_next().await? {
        for object in page.objects {
            println!("{}: {} bytes", object.key, object.size);
        }
        for folder in page.common_prefixes {
            println!("folder: {}", folder.prefix);
        }
    }
    Ok(())
}

/// Write an object with your own metadata, read its headers, copy it to another key.
pub async fn put_and_copy(bucket: &object_store::Bucket) -> Result<(), BoxError> {
    let object = bucket.object("reports/2026/november.txt");
    let etag = object.put(Body::new("hello", "text/plain"), 5)
        .edit_request(metadata([("owner", "finance")])?)
        .await?;
    let head = object.head().await?;
    println!("{:?}", head.get("x-amz-meta-owner"));
    bucket.object("reports/latest.txt")
        .copy_from("photos", "reports/2026/november.txt")
        .source_if_match(etag)
        .await?;
    Ok(())
}

/// The object again, only if it changed since its ETag. `None`: it did not (a `304`).
pub async fn if_changed(bucket: &object_store::Bucket, etag: &str) -> object_store::Result<Option<ByteStream>> {
    let answer = bucket.object("large.bin").get().send_if_none_match(etag).await?;
    Ok(answer.into_value())
}

/// The first kilobyte of an object, as a stream of chunks.
pub async fn first_kilobyte(bucket: &object_store::Bucket) -> object_store::Result<Vec<u8>> {
    let answer = bucket.object("large.bin").get().range("bytes=0-1023").send_full().await?;
    println!("{}", answer.status());                       // 206: a part of the object
    let mut stream = answer.into_value();
    let mut bytes = Vec::new();
    while let Some(piece) = stream.try_next().await? {
        bytes.extend_from_slice(&piece);
    }
    Ok(bytes)
}

/// An upload in parts (one part here; the last part may be small), aborted when a part fails.
pub async fn upload(bucket: &object_store::Bucket, data: Vec<u8>) -> object_store::Result<String> {
    let object = bucket.object("backup.bin");
    let started = object.create_multipart_upload().content_type("application/octet-stream").await?;
    let upload = object.upload(started.upload_id);
    let size = data.len() as u64;
    let etag = match upload.upload_part(1, Body::new(data, "application/octet-stream"), size).await {
        Ok(etag) => etag,
        Err(error) => {
            upload.abort().await?;
            return Err(error);
        }
    };
    let done = upload.complete(CompleteUpload::from_etags([(1, etag)])).await?;
    Ok(done.etag)
}
```

## What does not fit well, and the workaround

| S3 wants | What to write |
|---|---|
| A key with a whole segment `.` or `..` (`a/../b`), which is a valid key. | It cannot be sent in a path: the URL library under `reqwest` removes such a segment, when it parses a URL and in every setter of a path, and has no supported, portable way to keep it. Concord rejects the request when it is built, rather than send another key. To upload such a key, S3's form upload (a `POST` to the bucket) carries the key as a field of the form. |
| Metadata whose names the caller chooses: `x-amz-meta-*`. The description names every key. | `metadata([…])` above, passed to `.edit_request(…)`: the headers are added before the signer runs. |
| `content-md5` of the body of a `DeleteObjects`: a header computed from the bytes of the body. | The signer adds it for that endpoint, recognised by its name, before it signs. |
| An error inside a `200`, for a copy and for the end of an upload. | An arm on the 2xx that reads the root of the XML (`CopyReply`), and returns `Err(S3Problem)`: the client's own error. |
| Two markers that move together (the uploads in progress). | Your own pager with two slots, `uploads_after`. |
| A truncated page with no next marker, which should not end the list silently. | `.has_more(\|page\| page.is_truncated)`: a page that says more and gives no next marker is a Mismatch, after the page that arrived has been yielded; `uploads_after` returns a `Result` for the same reason. |
| A signature for the region of the bucket, and `us-east-1` for the list of buckets. | A middleware layer sees the request, not the description, so it chooses by `info.endpoint()`. |
| A large upload that survives a lost connection. A `Body::stream` is sent once, and `put` is `idempotent false;`. | An upload in parts, each in memory or a `Body::repeatable`: a retry policy, or your own loop, sends a part again. |
| An encoded string in a header: `x-amz-copy-source`. Concord does not percent-encode a header. | `copy_source` encodes it. |
