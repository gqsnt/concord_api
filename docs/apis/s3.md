# an object store like Amazon S3 in Concord
Written by GPT-6 (Codex), from the permitted Concord guide, the earlier endpoint checklist, and public AWS documentation, on 2026-11-12.

## The description

This is the eighteen-operation client for ordinary, general purpose S3 buckets. Object bytes are opaque; control documents and errors are XML. Directory buckets, access points, ACL administration, and encryption options are outside this subset. No service was contacted: the external reads were documentation pages.

The bucket handle takes a complete `Base`: either `https://photos.s3.eu-west-1.amazonaws.com` or `https://s3.eu-west-1.amazonaws.com/photos`. This keeps one endpoint tree for both addressing styles and accepts dotted bucket names without putting several labels into a host hole. The caller must give the bucket's signing region. The catalogue operation uses the global AWS host and its `us-east-1` signature scope. Other S3 deployments can change that endpoint's literal and the corresponding signer branch. These choices follow AWS's [addressing documentation](https://docs.aws.amazon.com/AmazonS3/latest/userguide/VirtualHosting.html) and [signature rules](https://docs.aws.amazon.com/AmazonS3/latest/developerguide/sig-v4-header-based-auth.html).

```rust
use aws_credential_types::Credentials;
use concord::{by_cursor, Base, Body, ByteStream};
use concord::read::Stream;
use crate::model::{
    BucketsPage, CompleteResult, CompleteUpload, CopyResult,
    CreateBucketConfiguration, DeleteBatch, DeleteResult, InitiatedUpload,
    ObjectsPage, PartsPage, UploadsPage,
};
use crate::wire::{
    checked_cursor, complete_ok, copy_ok, create_bucket_body,
    copy_source, uploads_after, Signed, Xml,
};

concord::api! {
    pub client ObjectStore(region: String, credentials: Credentials) {
        read Xml;
        problem crate::model::S3Problem;
        /// Signs every request, including each page and every retry.
        middleware Signed::new(credentials.clone(), region.clone());

        part version(version_id?: String) {
            query { "versionId" = version_id; }
        }
        part conditions(
            if_match?: String,
            if_modified_since?: String,
            if_unmodified_since?: String,
        ) {
            headers {
                "if-match" = if_match;
                "if-modified-since" = if_modified_since;
                "if-unmodified-since" = if_unmodified_since;
            }
        }
        part write_headers(
            content_type?: String,
            cache_control?: String,
            storage_class?: String,
        ) {
            headers {
                "content-type" = content_type;
                "cache-control" = cache_control;
                "x-amz-storage-class" = storage_class;
            }
        }
        part listing(prefix?: String, delimiter?: String) {
            query { prefix; delimiter; }
        }

        GET list_buckets(
            max_buckets?: u32, continuation_token?: String, prefix?: String,
        ) -> BucketsPage {
            base "https://s3.amazonaws.com";
            query {
                "max-buckets" = max_buckets;
                "continuation-token" = continuation_token;
                prefix;
            }
            paginate by_cursor(continuation_token, BucketsPage::next);
        }

        scope bucket(url: Base) {
            base url;

            /// Failure preserves the status and region header; 404 is not a boolean.
            HEAD head();
            /// Omit configuration in us-east-1; elsewhere give LocationConstraint.
            PUT create(configuration?: CreateBucketConfiguration) {
                body create_bucket_body(configuration);
                idempotent false;
            }
            DELETE delete();

            GET list_objects(
                max_keys?: u32, continuation_token?: String,
                start_after?: String, fetch_owner?: bool, ..listing,
            ) -> ObjectsPage {
                query {
                    "list-type" = "2";
                    "encoding-type" = "url";
                    "max-keys" = max_keys;
                    "continuation-token" = continuation_token;
                    "start-after" = start_after;
                    "fetch-owner" = fetch_owner;
                }
                paginate checked_cursor(continuation_token, ObjectsPage::next);
            }
            /// Per-key failures remain in DeleteResult, even on HTTP 200.
            POST delete_objects(batch: DeleteBatch) -> DeleteResult {
                query { "delete" = ""; }
                body crate::wire::xml(batch);
            }
            GET list_multipart_uploads(
                max_uploads?: u32, key_marker?: String,
                upload_id_marker?: String, ..listing,
            ) -> UploadsPage {
                query {
                    "uploads" = "";
                    "encoding-type" = "url";
                    "max-uploads" = max_uploads;
                    "key-marker" = key_marker;
                    "upload-id-marker" = upload_id_marker;
                }
                paginate uploads_after(key_marker, upload_id_marker);
            }

            scope object(key: String) {
                path "{*key}";

                GET get(range?: String, ..version, ..conditions) -> ByteStream {
                    headers { "range" = range; }
                    read Stream;
                }
                GET get_if_changed(
                    etag: String, range?: String, ..version, ..conditions,
                ) -> Option<ByteStream> {
                    headers { "if-none-match" = etag; "range" = range; }
                    read Stream;
                    status { 304 => None }
                }
                HEAD head(..version, ..conditions) -> http::HeaderMap {
                    status { 2xx { headers } => headers.as_map().clone() }
                }
                /// ETag is the value; send_full also keeps version/checksum headers.
                PUT put(file: Body, size: u64, ..write_headers) -> String {
                    headers { "content-length" = size; }
                    body file;
                    status { 2xx { headers } => headers.require("etag")?.to_owned() }
                    idempotent false;
                }
                PUT copy_from(
                    source_bucket: String, source_key: String,
                    source_version?: String, source_if_match?: String,
                    metadata_directive?: String, ..write_headers,
                ) -> CopyResult {
                    headers {
                        "x-amz-copy-source" = copy_source(source_bucket, source_key, source_version);
                        "x-amz-copy-source-if-match" = source_if_match;
                        "x-amz-metadata-directive" = metadata_directive;
                    }
                    status { 2xx { body } => copy_ok(body)? }
                    idempotent false;
                }
                DELETE delete(..version) {
                    idempotent version_id.as_ref().is_some_and(|id| id != "null");
                }
                POST create_multipart_upload(..write_headers) -> InitiatedUpload {
                    query { "uploads" = ""; }
                }

                scope upload(upload_id: String) {
                    query { "uploadId" = upload_id; }

                    PUT upload_part(part_number: u32, file: Body, size: u64) -> String {
                        query { "partNumber" = part_number; }
                        headers { "content-length" = size; }
                        body file;
                        status { 2xx { headers } => headers.require("etag")?.to_owned() }
                    }
                    POST complete(parts: CompleteUpload) -> CompleteResult {
                        body crate::wire::xml(parts);
                        status { 2xx { body } => complete_ok(body)? }
                    }
                    DELETE abort();
                    GET list_parts(
                        max_parts?: u32, part_number_marker?: u32,
                    ) -> PartsPage {
                        query {
                            "max-parts" = max_parts;
                            "part-number-marker" = part_number_marker;
                        }
                        paginate checked_cursor(part_number_marker, PartsPage::next);
                    }
                }
            }
        }
    }
}
```

The eighteen leaves are: ListBuckets; Head/Create/DeleteBucket; ListObjectsV2, DeleteObjects, ListMultipartUploads; GetObject, conditional GetObject, Head/Put/Copy/DeleteObject; CreateMultipartUpload, UploadPart, CompleteMultipartUpload, AbortMultipartUpload, ListParts. The conditional GET is a second description of GetObject, as in the checklist.

`{*key}` preserves `/`, repeated slashes, and trailing slashes. It still rejects a standalone `.` or `..` segment: `a/../b` is a valid S3 key which this client cannot address. A transport beneath Concord cannot restore a key rejected during building. The documented door is another HTTP library that preserves the path, or the provider SDK; no such request is performed here. AWS documents these [key cases](https://docs.aws.amazon.com/AmazonS3/latest/userguide/object-keys.html).

`get` accepts one HTTP byte range, such as `bytes=0-1023`; both 200 and 206 hand over a stream. A caller requiring a range checks the status and Content-Range with `send_full`. Conditional dates are HTTP-date strings. A failed precondition stays a 412 error. Neither bucket HEAD nor object HEAD turns permission-dependent statuses into absence. See [GetObject](https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetObject.html) and [HeadObject](https://docs.aws.amazon.com/AmazonS3/latest/API/API_HeadObject.html).

## Beside the macro

`model` contains ordinary owned Serde types, named below rather than expanded. Repeated elements have `#[serde(default)]`; optional elements have `Option`; XML names are explicit, unknown fields are accepted, and timestamps/ETags/IDs remain strings. The only complete type declarations below are the two behaviour carriers `Xml` and `Signed`.

| Type | XML shape / Rust fields used here |
|---|---|
| `S3Problem` | Error: Code → `code`, Message → `message`, optional RequestId, HostId, Resource; implements `Error`, `Display`, `Debug`, `Deserialize`. |
| `BucketsPage`, `BucketInfo`, `BucketList` | ListAllMyBucketsResult: Buckets → `buckets: BucketList`, whose Bucket → `items: Vec<BucketInfo>`; each item has name, creation_date, optional bucket_region; ContinuationToken → `continuation_token: Option<String>`. |
| `ObjectsPage`, `ObjectInfo`, `CommonPrefix` | ListBucketResult: Contents → `objects: Vec<ObjectInfo>` (key, etag, size); CommonPrefixes → `common_prefixes: Vec<CommonPrefix>` (prefix); IsTruncated → `is_truncated: bool`, NextContinuationToken → `next_continuation_token: Option<String>`. |
| `UploadsPage`, `UploadInfo` | ListMultipartUploadsResult: Upload → `uploads: Vec<UploadInfo>` (key, upload_id, initiated); common_prefixes; is_truncated; next_key_marker and next_upload_id_marker, both `Option<String>`. |
| `PartsPage`, `PartInfo` | ListPartsResult: Part → `parts: Vec<PartInfo>` (part_number: u32, etag, size: u64); is_truncated; NextPartNumberMarker → `next_part_number_marker: Option<u32>`. |
| `CreateBucketConfiguration` | Root CreateBucketConfiguration; `xmlns` serialized as `@xmlns`; location_constraint as LocationConstraint. |
| `DeleteBatch`, `DeleteTarget` | Root Delete: `xmlns` as `@xmlns`, objects as repeated Object containing Key and optional VersionId; quiet as Quiet. |
| `DeleteResult`, `Deleted`, `DeleteFailure` | Root DeleteResult: Deleted → `deleted: Vec<Deleted>` and Error → `errors: Vec<DeleteFailure>`; each preserves key/version; failures also code/message. |
| `InitiatedUpload` | InitiateMultipartUploadResult: bucket, key, upload_id. |
| `CompleteUpload`, `CompletedPart` | Root CompleteMultipartUpload: `xmlns` as `@xmlns`; parts as repeated Part containing PartNumber and ETag, in ascending order. |
| `CopyResult`, `CompleteResult` | CopyObjectResult: etag, last_modified; CompleteMultipartUploadResult: location, bucket, key, etag. |
| `CopyReply`, `CompleteReply` | Serde externally tagged enums: respectively `Success(CopyResult)` renamed CopyObjectResult or `Success(CompleteResult)` renamed CompleteMultipartUploadResult; both have `Error(S3Problem)` renamed Error. |

Request constructors fill `xmlns` with `http://s3.amazonaws.com/doc/2006-03-01/`; absent optional request elements are skipped. `DeleteBatch::keys` makes quiet=false entries with no VersionId and validates 1–1000 keys. `CompleteUpload::from_etags` validates part numbers/order. These are ordinary model constructors, omitted. The provider requires the bulk-delete checksum and reports [individual failures](https://docs.aws.amazon.com/AmazonS3/latest/API/API_DeleteObjects.html); completion needs the [part numbers and ETags](https://docs.aws.amazon.com/AmazonS3/latest/API/API_CompleteMultipartUpload.html).

Listings ask for URL encoding so XML can carry awkward keys. On the documented key/prefix fields, models use `url_text` below, and an optional equivalent implemented with `Option::<String>::deserialize` plus `map(...).transpose()`. This includes NextKeyMarker for multipart listings. Continuation tokens and upload IDs are opaque and are never decoded. See [ListObjectsV2](https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListObjectsV2.html) and [ListMultipartUploads](https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListMultipartUploads.html).

All following Rust is in `wire`; imports are shared by its snippets. Dependencies are quick-xml with `serialize`, serde with `derive`, percent-encoding, base64, md-5, and the AWS credentials/signing crates. The AWS signer supplies the cryptography; it makes no requests. Its [documented HTTP adapter](https://docs.rs/aws-sigv4/latest/aws_sigv4/http_request/index.html) accepts an already encoded URI. Nothing here is compiled, as requested.

The XML reader is bounded; a malformed or oversized document is a Mismatch. `CopyReply` and `CompleteReply` choose their enum variant by the XML root, rather than guessing from optional fields. The small arm functions turn an Error document inside 200 into the client's typed refusal. This is needed for [copy](https://docs.aws.amazon.com/AmazonS3/latest/API/API_CopyObject.html) and [completion](https://docs.aws.amazon.com/AmazonS3/latest/API/API_CompleteMultipartUpload.html); the enum mapping follows [quick-xml's top-level enum representation](https://docs.rs/quick-xml/latest/quick_xml/de/index.html#normal-enum-variant).

```rust
impl<T: DeserializeOwned + Send> Reader<T> for Xml {
    async fn read(&self, body: Incoming) -> Result<T, ReadError> {
        let bytes = body.bytes(10 * concord::MIB).await?;
        quick_xml::de::from_reader(&bytes[..])
            .map_err(|error| ReadError::not_the_type(bytes, error))
    }
}
pub fn xml<T: Serialize>(value: &T) -> Result<Body, quick_xml::SeError> {
    Ok(Body::new(quick_xml::se::to_string(value)?, "application/xml"))
}
pub fn create_bucket_body(value: &Option<CreateBucketConfiguration>) -> Result<Body, BoxError> {
    match value {
        Some(config) => Ok(xml(config)?),
        None => Ok(Body::new("", "application/xml")),
    }
}
pub fn copy_ok(reply: CopyReply) -> Result<CopyResult, S3Problem> {
    match reply { CopyReply::Success(value) => Ok(value), CopyReply::Error(e) => Err(e) }
}
pub fn complete_ok(reply: CompleteReply) -> Result<CompleteResult, S3Problem> {
    match reply { CompleteReply::Success(value) => Ok(value), CompleteReply::Error(e) => Err(e) }
}
pub fn url_text<'de, D: Deserializer<'de>>(input: D) -> Result<String, D::Error> {
    let text = String::deserialize(input)?;
    percent_encoding::percent_decode_str(&text).decode_utf8()
        .map(|value| value.into_owned()).map_err(serde::de::Error::custom)
}
fn encoded(text: &str, keep_slashes: bool) -> String {
    let mut result = String::new();
    for byte in text.bytes() {
        if byte.is_ascii_alphanumeric() || b"-._~".contains(&byte) || (keep_slashes && byte == b'/') {
            result.push(byte as char);
        } else {
            use std::fmt::Write;
            write!(&mut result, "%{byte:02X}").expect("writing to a String");
        }
    }
    result
}
pub fn copy_source(bucket: &String, key: &String, version: &Option<String>) -> String {
    let mut source = format!("/{}/{}", encoded(bucket, false), encoded(key, true));
    if let Some(id) = version { source.push_str(&format!("?versionId={}", encoded(id, false))); }
    source
}
```

Header entries do not percent-encode their values. `copy_source` therefore performs the encoding required for [x-amz-copy-source](https://docs.aws.amazon.com/AmazonS3/latest/API/API_CopyObject.html) itself; a key or version containing `%`, `?`, space, or Unicode stays unambiguous.

The checked pager honours IsTruncated rather than page length. Missing promised cursors fail on the next `try_next`, after the received page was given. The two-marker pager moves both slots, preserving every filter. The catalogue has a simpler [continuation-token rule](https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListBuckets.html); its callers should set max_buckets to request pagination. Parts use the provider's [NextPartNumberMarker](https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListParts.html), not an offset computed from item count.

```rust
impl BucketsPage {
    pub fn next(&self) -> Option<String> { self.continuation_token.clone() }
}
fn truncated_next<T: Clone>(more: bool, next: &Option<T>) -> Result<Option<T>, Fail<S3Problem>> {
    if !more { return Ok(None); }
    next.clone().map(Some).ok_or_else(|| concord::mismatch("truncated page without next marker"))
}
impl ObjectsPage {
    pub fn next(&self) -> Result<Option<String>, Fail<S3Problem>> {
        truncated_next(self.is_truncated, &self.next_continuation_token)
    }
}
impl PartsPage {
    pub fn next(&self) -> Result<Option<u32>, Fail<S3Problem>> {
        truncated_next(self.is_truncated, &self.next_part_number_marker)
    }
}
pub fn checked_cursor<C, S, V>(slot: S, next: fn(&C::Value) -> Result<Option<V>, Fail<S3Problem>>)
    -> impl Fn(C, &Answer<C::Value>) -> Result<Option<C>, Fail<S3Problem>> + Send + 'static
where C: Call<Problem = S3Problem>, S: Slot<C, Value = V>, V: Send + 'static {
    move |call, answer| Ok(next(answer.value())?.map(|value| slot.set(call, value)))
}
pub fn uploads_after<C, K, U>(key: K, upload: U)
    -> impl Fn(C, &Answer<UploadsPage>) -> Result<Option<C>, Fail<S3Problem>> + Send + 'static
where C: Call<Value = UploadsPage, Problem = S3Problem>,
      K: Slot<C, Value = String>, U: Slot<C, Value = String> {
    move |call, answer| {
        let page = answer.value();
        if !page.is_truncated { return Ok(None); }
        let next_key = page.next_key_marker.clone()
            .ok_or_else(|| concord::mismatch("truncated uploads without key marker"))?;
        let next_upload = page.next_upload_id_marker.clone()
            .ok_or_else(|| concord::mismatch("truncated uploads without upload marker"))?;
        Ok(Some(upload.set(key.set(call, next_key), next_upload)))
    }
}
```

The metadata door is a fallible preparation function plus infallible `edit_request`. It owns validated headers before the call is built. The caller supplies suffixes, never an Authorization or arbitrary transport header. It applies to put, copy with REPLACE, and multipart initiation. Response metadata is already present in HEAD's HeaderMap or `send_full().headers()`. This follows the [REST metadata prefix](https://docs.aws.amazon.com/AmazonS3/latest/userguide/UsingMetadata.html).

```rust
pub fn metadata<K: AsRef<str>, V: AsRef<str>>(
    entries: impl IntoIterator<Item = (K, V)>,
) -> Result<impl Fn(&mut reqwest::Request) + Send + Sync + 'static, BoxError> {
    let mut headers = Vec::new();
    for (suffix, value) in entries {
        if suffix.as_ref().is_empty() { return Err("empty metadata name".into()); }
        let name = HeaderName::from_bytes(format!("x-amz-meta-{}", suffix.as_ref()).as_bytes())?;
        headers.push((name, HeaderValue::from_str(value.as_ref())?));
    }
    Ok(move |request| {
        for (name, value) in &headers { request.headers_mut().insert(name.clone(), value.clone()); }
    })
}
fn delete_checksum(request: &mut reqwest::Request) -> Result<(), BoxError> {
    let bytes = request.body().and_then(|body| body.as_bytes())
        .ok_or("bulk delete must have a buffered XML body")?;
    let digest = STANDARD.encode(Md5::digest(bytes));
    request.headers_mut().insert("content-md5", HeaderValue::from_str(&digest)?);
    Ok(())
}
```

The signer also installs bulk-delete's checksum over the actual serialized bytes, before signing. That endpoint-name branch is deliberate pain: `body` carries Content-Type but offers no general body-derived header result. The middleware never follows a redirect. A wrong-region response is returned with its headers; an application rebuilds the client/handle for that region. This avoids signing a second location below the middleware.

Buffered bodies are hashed by the AWS signer. A streaming upload uses the documented UNSIGNED-PAYLOAD mode over HTTPS with an explicit length; the request itself is still signed. Policies requiring signed payload bytes need buffered multipart parts, or an aws-chunked body encoder outside this subset. Acceptance of that streaming mode by a particular S3-compatible provider is (unsure). Each retry gets a fresh timestamp and signature; one-shot upload bodies still cannot be replayed. See the [S3 canonicalization rules](https://docs.aws.amazon.com/AmazonS3/latest/developerguide/sig-v4-header-based-auth.html) and [signing settings](https://docs.rs/aws-sigv4/latest/aws_sigv4/http_request/struct.SigningSettings.html).

```rust
impl Signed {
    pub fn new(credentials: Credentials, region: String) -> Self { Self { credentials, region } }
    fn apply(&self, request: &mut reqwest::Request, endpoint: &str) -> Result<(), BoxError> {
        let now = SystemTime::now();
        if self.credentials.expiry().is_some_and(|expiry| expiry <= now) {
            return Err("expired signing credentials".into());
        }
        if endpoint == "object_store.bucket.delete_objects" { delete_checksum(request)?; }
        for name in ["authorization", "x-amz-date", "x-amz-security-token", "x-amz-content-sha256", "host"] {
            request.headers_mut().remove(name);
        }
        let identity: Identity = self.credentials.clone().into();
        let region = if endpoint == "object_store.list_buckets" { "us-east-1" } else { &self.region };
        let mut settings = SigningSettings::default();
        settings.percent_encoding_mode = PercentEncodingMode::Single;
        settings.uri_path_normalization_mode = UriPathNormalizationMode::Disabled;
        settings.payload_checksum_kind = PayloadChecksumKind::XAmzSha256;
        let params: SigningParams<'_> = v4::SigningParams::builder()
            .identity(&identity).region(region).name("s3").time(now).settings(settings).build()?.into();
        let payload = match request.body() {
            None => SignableBody::Bytes(&[]),
            Some(body) => match body.as_bytes() {
                Some(bytes) => SignableBody::Bytes(bytes),
                None => {
                    if request.url().scheme() != "https" || !request.headers().contains_key("content-length") {
                        return Err("stream upload needs HTTPS and Content-Length".into());
                    }
                    SignableBody::UnsignedPayload
                }
            },
        };
        let headers = request.headers().iter()
            .map(|(name, value)| Ok((name.as_str(), value.to_str()?)))
            .collect::<Result<Vec<_>, http::header::ToStrError>>()?;
        let signable = SignableRequest::new(
            request.method().as_str(), request.url().as_str(), headers.into_iter(), payload,
        )?;
        let (instructions, _) = sign(signable, &params)?.into_parts();
        for (name, value) in instructions.headers() {
            let mut value = HeaderValue::from_str(value)?;
            value.set_sensitive(name == "authorization" || name == "x-amz-security-token");
            request.headers_mut().insert(HeaderName::from_bytes(name.as_bytes())?, value);
        }
        Ok(())
    }
}
impl Middleware for Signed {
    async fn handle(&self, mut request: reqwest::Request, info: TryInfo, next: Next<'_>)
        -> Result<reqwest::Response, TransportError> {
        self.apply(&mut request, info.endpoint())
            .map_err(|error| TransportError::blocked().with_source(error))?;
        next.send(request, info).await
    }
}
```

This uses caller-supplied, already resolved credentials, including an optional session token. It does not fetch credentials or refresh them. `Credentials` provides the signer's access and secret material; generated placement never serializes it. `Signed` has no Debug implementation, and it explicitly marks the emitted Authorization and session-token values sensitive. `request()` remains unsigned, as the guide promises; a fake transport would see the signed request. No fake or network call was run.

## Calling it

The six pieces are examples to read, never executed. They share `store` and `bucket` from the first piece, run in async code returning a boxed error, and import `futures_util::TryStreamExt` and `tokio::io::AsyncWriteExt` where needed. `config`, `output`, and `cached_etag` are application values.

1. Connect to a region, choose addressing, and inspect the bucket catalogue.

```rust
let credentials = Credentials::new(access_key, secret_key, session_token, None, "application");
let store = ObjectStore::new("eu-west-1", credentials);
let bucket = store.bucket("https://photos.s3.eu-west-1.amazonaws.com".parse::<Base>()?);
let path_style = store.bucket("https://s3.eu-west-1.amazonaws.com/photos".parse::<Base>()?);
let mut catalogue = store.list_buckets().max_buckets(1000).pages();
while let Some(page) = catalogue.try_next().await? { println!("{} buckets", page.buckets.items.len()); }
path_style.head().await?;
// To create an owned, unused name: store.bucket(new_bucket_base).create().configuration(config).await?;
```

2. Walk every objects page, retaining folder-like common prefixes too.

```rust
let mut pages = bucket.list_objects().prefix("reports/").delimiter("/").max_keys(500).pages();
```

3. Upload with user metadata, inspect HEAD, and copy to another key.

```rust
let object = bucket.object("reports/2026//november.txt");
let etag = object.put(Body::new("hello", "text/plain"), 5)
```

6. Upload a buffered multipart part and complete, with explicit cleanup on part failure.

```rust
let object = bucket.object("backup.bin");
let started = object.create_multipart_upload().content_type("application/octet-stream").await?;
let upload = object.upload(started.upload_id);
let data = vec![0_u8; 5 * 1024 * 1024];
let size = data.len() as u64;
let etag = match upload.upload_part(1, Body::new(data, "application/octet-stream"), size).await {
    Ok(etag) => etag,
    Err(error) => { let _ = upload.abort().await; return Err(error.into()); }
};
let observed = upload.list_parts().max_parts(1000).send().await?;
assert_eq!(observed.parts.len(), 1);
let completed = upload.complete(CompleteUpload::from_etags([(1, etag)])?).await?;
println!("{}", completed.etag);
```

That final example has one part, so it is also the last part; larger backups loop over bounded parts. An application persists the upload ID/ETags for recovery and can enumerate unfinished sessions with `bucket.list_multipart_uploads().pages()`. Completion's ambiguous failures need reconciliation before deciding to complete again or abort. Nothing in the tree automates the whole transaction. UploadPart replaces a part with the same number; PutObject and CopyObject may create new versions, hence the conservative `idempotent false` marks ([UploadPart](https://docs.aws.amazon.com/AmazonS3/latest/API/API_UploadPart.html), [PutObject](https://docs.aws.amazon.com/AmazonS3/latest/API/API_PutObject.html)).
