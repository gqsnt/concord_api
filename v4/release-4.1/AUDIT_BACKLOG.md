# Audit backlog for the next campaign

Questions deliberately left for the planned cross-model audit (Sol, Terra, Opus, DeepSeek). This
release closure did not execute them. Each row names where the behaviour lives and what tests it
today; an auditor starts there, writes a failing case first, and records the outcome. Paths are
relative to the repository root.
