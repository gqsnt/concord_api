**OPUS-1 — remaining repository-binding defect.** Classification **correctness defect**, severity **medium**, evidence **reproduced and source-confirmed**. `paging.rs:269` checks the origin and collection shape; `paging.rs:365` recognizes any digit-only numeric repository ID; `paging.rs:308` substitutes `self.binding.repo` without knowing which repository the ID identifies. Reproduce with `cargo test --offline --locked --manifest-path review/sol-recheck/probes/Cargo.toml --test github numeric_repo_link_is_rebound_across_repositories -- --nocapture` (use the scratch target/TMPDIR from COMMANDS.sh). Observed:

```text

```

The probe first confirms that B refuses A's in-memory key. It then restores the identical raw URL through B, asserts the changed binding and records the request. Probe: `probes/tests/github.rs:78`; output: `logs/probes-github.log`. Persist URL plus original binding and compare it on restore, or accept a verified repository-ID mapping. Simply refusing all numeric links would break the legitimate numeric continuation form this adapter supports.

The independent restore matrix (`probes/tests/github.rs:19`) checks 32 path/query variants plus foreign host/scheme/port. Different named owner/repository, parent, operation, path prefix, extra path segments, encoded slashes/dot traversal, and wrong paths disguised by query/fragment are refused before I/O. Operation/base path case changes, trailing slashes, zero-padded parent numbers and percent-escaped unreserved path characters are refused. These are conservative exact-path decisions; no live evidence here establishes that GitHub emits those escaped/case/trailing-slash variants. Same-path query/fragment text cannot change the collection binding; fragments do expose the separate progress-check problem below.

**ASTRA-2 — header-name memory and byte compatibility.** Inferred names are serializer-owned `&'static str` references (`crates/concord-extras/src/csv/names.rs:170`/`:241`), retained as such by `write.rs:244`/`:402`. Input construction (`columns`/`with_columns` take ownership), arbitrary user serializers, reference-list allocations, and collected finite output are separate costs.
