# H03 Exact inputs infer: natural caller spellings compile without annotations

Family: INPUT
Status: PRE-REGISTERED on `concord-desirability` before any implementation; base = the head that
carries this card (H04 and H08 accepted). Thresholds below are frozen; no candidate exists yet.
Decision path: design hypothesis (PLAN_AMENDMENT_A1 §3); pilot, then migrate.

## Problem (measured / recorded)
- Every generated input except `maybe_*` and the client `Config` fields takes `impl IntoValue<T>`
  (`crates/concord-macros/src/emit.rs` `positional_params`, setters, parameter-group setters,
  initializers). Because the parameter is generic, an argument whose type comes from its use —
  `Default::default()`, `.into()`, `.parse()?` — has nothing to infer from: rustc reports E0283.
  The trait is sealed and, for every declared type other than `String` and `HeaderValue`, accepts
  only `T` itself (impls: `T`, `&str`/`&String` → `String`, `&HeaderValue` → `HeaderValue`).
  Survey: `reviews/h03-design-survey.md`.
- I5 caller bank at B: all 5 `default_body` cases fail (the first error names `IntoValue`,
  `__macro`, `concord_core::`); `into_body` cases also get E0283 (scored as passes only because the
  internal names sit outside the headline).
- Recorded caller friction: Kraken `Default::default()` needs the options type imported and named
  (`kraken-spot-rest-sdk/FIRST_USE.md`); Frankfurter `.parse()` needs `::<Date>`
  (`frankfurter-sdk/FRICTION.md`); Cloudflare newtype ids cannot take `"z".into()`
  (`cloudflare-zones-sdk/FRICTION.md`); Square's `set_*` and `maybe_*` accept different things.

## Comparator
- **Baseline:** current generic `impl IntoValue<T>` parameters (best workaround: name the type,
  turbofish, or `T::default()`).
- **Alternative A (hybrid exact inputs):** generated inputs take exactly `T` for every declared
  type except one whose last path segment is `String` or `HeaderValue`, which keep `IntoValue<T>`
  (so `"lit"` and `&string` still work where they work today). Positions: positional required
  values and bodies, `set_x`, parameter-group setters, initializers.
- **Alternative B (A + named generics):** as A, and the remaining `IntoValue` positions use a named
  generic parameter instead of an `impl` argument, so an E0283 there names a type parameter, not
  Concord's internal path.

## Witnesses, contrary case, controls
| SDK | Role | What must hold |
|---|---|---|
| Kraken | witness (body `Default::default()`) | `balances(Default::default(), ..)` compiles and sends the intended request |
| Cloudflare | witness (newtype ids, body) | `zone("z".into())`-style and `Default::default()` bodies compile where the newtype has the conversion |
| Notion | witness (body) | `query(id, Default::default())` compiles |
| Frankfurter | witness (`.parse()`) | a parsed date argument infers without turbofish |
| Nager | contrary case (`String` positional) | `holidays("AT", 2026)` and `&String` arguments keep compiling unchanged |
| PokeAPI | simple control | no caller change, no new ceremony |

## Outcomes (A1 §2.2) and instruments
Primary — **complete ordinary use:** a deterministic **idiom corpus** (sealed, built after the
candidates freeze by a lane the implementers never see): per witness and control, caller snippets
in natural spellings (`Default::default()`, `.into()`, `.parse()?`, literals into newtypes via
`.into()` where the newtype provides it, `&str`/`&String` for `String` values, integer literals),
each with its intended request; compiled in the I3 R3 sandbox and run against a local receiver.
Score per arm: snippets that compile **and** send the intended request. Every snippet that works on
the baseline must still work on the candidate (no regression).
Secondary — **diagnose and recover:** I5 caller bank re-run per arm with the seeded lines relabelled
(a seeded line that now compiles and sends the intended request counts as resolved, one that
compiles with a wrong request as a failure); the `wrong_setter` cases' first error must still name
the expected type; no case newly names Concord internals.

Costs (gates where bounded): call sites changed (tests, docs, examples) with each listed; public
rustdoc JSON diff (signatures change from `impl IntoValue<T>` to `T`); concept count (expected to
fall: the "annotate `Default::default()`" rule disappears); `benches/scale/ab.sh` compile time and
expanded size within +5%; full gate and CI Linux/Windows on the exact candidate; independent
review.

## Decision (thresholds frozen here; pilot triage rules, not statistics)
- **WIN (A or B):** on the witnesses, the corpus success rate rises by ≥ 20 points over baseline
  and every witness gains ≥ 1 newly working spelling; 0 corpus regressions on any SDK (witnesses,
  contrary case, control); Nager and PokeAPI need no caller change; I5: no case newly names
  internals and every `wrong_setter` first error names the expected type; existing tests change
  only at sites the change requires (each listed; aliases of `String`/`HeaderValue` reported);
  guardrails and gates pass.
- **B instead of A:** only if B meets every A condition and also removes Concord's internal path
  from the remaining E0283 labels (I5) without new breakage.
- **KEEP_CURRENT:** the corpus gain is < 20 points or comes with regressions the alternatives
  cannot avoid.
- **LOSS:** a gate failure; any corpus regression; a `wrong_setter` diagnostic that no longer names
  the expected type; a required caller change in a control.
- **INCONCLUSIVE:** gains on only one witness; corpus or harness cannot be built for a witness.
- A WIN leads to full migration (every SDK, the docs that state the conversion rule, the UI tests
  whose expected errors change, the `IntoValue` doctest), the broad gate and CI, before ACCEPT.

## Concept budget
0 new public concepts; the rule "a generic input cannot infer `Default::default()`/`.into()`/
`.parse()`" is removed for non-`String` types. `IntoValue` stays for `String`/`HeaderValue`.

## Kill conditions
Defaults (DECISION_RULE) + any newly rejected caller spelling that compiles today; a change to how a
value is sent (only its accepted Rust spellings may change).
