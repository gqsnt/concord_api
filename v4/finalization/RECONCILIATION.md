## Compact compatibility set (addendum §4)

`examples/compat`: a downstream crate on edition 2021, with a private client, local fixtures only
and a loopback server. It covers eight cases; the assumptions of each are sourced or labelled
synthetic in the crate's README:
1. response metadata kept while decoding, and status metadata read without consuming the error;
2. an application error envelope inside a 2xx, handled explicitly by a typed output or a custom
   decoder;
3. flat `form` versus a bracket-nested encoding through a custom format;
4. a multi-segment resource key through the native exit (literal `/` versus encoded `%2F`);
5. JSON with `application/apply-patch+yaml` (Kubernetes server-side apply);
6. a fresh idempotency value per request handle, kept by an explicit clone, never shared from a
   client default;
7. a refreshed base or root value while earlier snapshots keep their selection;
8. native and literal key aliases with `Content-Type` and sensitivity under remove, replace and
   `cfg`.

Query spaces are not compared byte for byte against other libraries: the case records what the
locked `url` serializer emits (`+` for a space in a query value) as Concord's contract.
