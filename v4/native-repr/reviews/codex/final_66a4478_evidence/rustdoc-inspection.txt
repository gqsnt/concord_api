Source pub fn with_base_url (self, url: impl AsRef < str >) -> Result <Self, Error> Replaces the declared base URL (for example with a staging server or a local test server). It must be an http / https URL with a host, no port 0 and no user information, query or fragment; anything else is an error. Declared paths are appended to its path. With subdomain labels the host must be a domain name: to reach a local server, keep a domain and map it with reqwest::ClientBuilder::resolve . Returns a new handle: scopes and requests created from the old one keep the old base. Source pub fn set_native (self, value: impl IntoValue<HeaderValue>) -> Self Replaces native . Required: supplied when the client is created. Sent as: header x-native . As a header value it goes through concord::ToHeaderValue : a native HeaderValue is sent byte for byte and keeps its sensitivity flag; text must be visible ASCII, space or tab; integers and bool are written in decimal / true / false .
