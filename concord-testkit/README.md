# concord-testkit

Tools for testing a client that Concord generates. Concord is the crate `concord-api`,
used as `concord` in code.

- `Server`: a real local HTTP/1.1 server, scripted by the test. It records every request exactly as it arrived.
- `Script`: a transport with virtual time and no socket. Under `start_paused = true`, an hour passes instantly.

For a plain response, `concord::fake` is enough. Use this kit when a test depends on time
(a retry, a timeout), or on the bytes that were actually sent.

Your tests depend on it as a dev-dependency; your library never does. `start_paused` comes
from Tokio's `test-util` feature, and it works on the current-thread runtime only (the default
flavor of `#[tokio::test]`). `Script` also works on a multi-thread runtime
(`#[tokio::test(flavor = "multi_thread")]`, with tasks that share one client): its clones share
one record behind a lock, the scripted attempts are played in the order the requests reach it,
and its waits (`after`, `pause`) then take real time, since the clock is not paused.

The crates are not on crates.io yet. Until they are, add it as a Git dependency:

```toml
[dev-dependencies]
concord-testkit = { git = "https://github.com/gqsnt/concord_api" }
tokio = { version = "1", features = ["macros", "rt", "test-util"] }
```

Once the crates are published on crates.io, the first line becomes `concord-testkit = "5.0.0-rc.1"`.

In this example, `Tasks` is a client generated by `concord::api!`, with `GET get(id: u64) -> Task` (the client of [the tour](https://github.com/gqsnt/concord_api/blob/main/docs/guide/tour.md)).

```rust
use concord_testkit::Script;
use std::time::Duration;
use tokio::time::Instant;

#[tokio::test(start_paused = true)]
async fn a_silent_server_ends_the_call_after_30_seconds() {
    let script = Script::new();
    script.never();                                  // this attempt never gets a response
    let tasks = Tasks::new().with_transport(script.clone());

    let start = Instant::now();
    let error = tasks.get(7).await.unwrap_err();
    assert_eq!(start.elapsed(), Duration::from_secs(30));
    assert_eq!(
        error.to_string(),
        "transport error: no answer for 30 s (with_idle_timeout changes it), in tasks.get"
    );
}
```

See [testing a client](https://github.com/gqsnt/concord_api/blob/main/docs/guide/testing.md) for a retry on virtual time, a local server, and what each method of `Script` and `Server` does.

Minimum Rust version: 1.96.
