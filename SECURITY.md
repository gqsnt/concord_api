# Security policy

## Supported versions

The latest Concord release candidate receives security fixes. See the [changelog](CHANGELOG.md) for the release history.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting for this repository](https://github.com/gqsnt/concord_api/security/advisories/new). Include the Concord version or Git revision, the affected features, and a small reproduction with dummy credentials. Describe who could trigger the fault and what it exposes or changes. Keep the report in the private advisory while a fix is being prepared.

The maintainer will acknowledge the report, ask for any details needed to reproduce it, and share the result of the investigation. For a confirmed vulnerability, the maintainer will coordinate a fix and disclosure with you through the advisory.
